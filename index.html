COMMENT JOUER

Observer. Prévoir. Agir.

Le plateau montre tous les zombies et les chemins. Chaque action consomme un tour, puis les zombies avancent. Avant toute décision, vous pouvez voir leur déplacement prévu en pointillés et le rayon sonore qui les attirera.

Déplacer : choisissez l'allure puis cliquez une destination. Interagir : cliquez une porte, le boîtier de l'alarme ou les médicaments quand vous êtes tout près. Bouteille : choisissez le bouton puis une case à six cases maximum. Tirer : ciblez un zombie visible.

Une alarme attire pendant cinq tours. Les zombies ne sont pas intelligents : ils vont vers ce qu'ils voient ou entendent. Les barrières et les portes changent leurs itinéraires. Vous pouvez gagner sans tirer.
